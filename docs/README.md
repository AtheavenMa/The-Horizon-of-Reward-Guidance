# Documentation

The repository separates **mathematical guarantees**, **numerical demonstrations**, and **software checks**. The paper is the authoritative source for every theorem.

- [Theory and assumptions](THEORY.md) explains the scalar exact horizon, corridor condition, ordinary-PG local separation, and BTL bounds.
- [Python API](API.md) gives parameter and input conventions, return values, and limitations.
- [Paper-reported results](PAPER_RESULTS.md) identifies values from the frozen JSON/CSV ledger, with all experimental scopes.
- [Reproduction instructions](REPRODUCE.md) lists exact commands, seeds, file mapping, and artifact tests.
- [Figure map](FIGURE_MAP.md) maps all seven manuscript figures to their source results.
- [Scope and limitations](SCOPE.md) distinguishes what this code does and does not claim.

For the fastest introduction, start with [the main README](../README.md) and run `python demo/demo.py` from the repository root.
